# Step 11 — figures/

The exact experiment PNGs the Step 11 deliverables cite. Every figure must trace to a real
artifact under `implementation/step11/implementation/plots/`; nothing here is fabricated.
Implementation-plot figures are prefixed `impl_`.

**Status: the experiment PNGs were produced on the run and exist** (matplotlib was active on the
executing machine). They just need copying into this folder. The **conceptual diagrams** are
generated by the `summary/make_*_figure.py` scripts (a human step; the agent does not run code).

---

## How to assemble them (human step)

The experiment PNGs already exist; copy them here (from `rlPlanRevised/`, PowerShell):

```powershell
# implementation plots -> figures/ with impl_ prefix
Copy-Item implementation/step11/implementation/plots/coalition_graph.png     deliverables/reports/step11/figures/impl_coalition_graph.png
Copy-Item implementation/step11/implementation/plots/coalition_timeline.png  deliverables/reports/step11/figures/impl_coalition_timeline.png
Copy-Item implementation/step11/implementation/plots/shapley_attribution.png deliverables/reports/step11/figures/impl_shapley_attribution.png
Copy-Item implementation/step11/implementation/plots/sweep_coalition_gap.png deliverables/reports/step11/figures/impl_sweep_coalition_gap.png
Copy-Item implementation/step11/implementation/plots/spinning_top.png        deliverables/reports/step11/figures/impl_spinning_top.png
```

If you need to (re)generate the experiment PNGs first (needs `matplotlib`):

```bash
cd rlPlanRevised/implementation/step11/implementation
python tournament.py --config scale    # -> results/scale_results.json
python sweep.py --tier scale           # -> results/sweep_scale.json + plots/sweep_coalition_gap.png
python plotting.py --config scale      # -> plots/*.png
```

The conceptual-diagram PNGs are produced by the `summary/make_*_figure.py` scripts (human step):

```bash
cd rlPlanRevised/deliverables/reports/step11/summary
python make_sls_coalition_figure.py   # -> sls_coalition.png
python make_shapley_figure.py         # -> shapley_credit.png
python make_mappo_figure.py           # -> mappo_blend.png
python make_egta_figure.py            # -> egta_spinning_top.png
```

Then build the PDFs (toolchain: pandoc + tectonic; not present on the authoring machine):

```bash
python3 scripts/build_reports.py --step step11 --lang en
# -> deliverables/reports/step11/step11_report_en.pdf
# -> deliverables/summaries/step11_en.pdf
```
