## 2. Игрови двигател за Ледюк покер

Пълна реализация, съответстваща на семантиката на OpenSpiel: шест карти ({J, Q, K} × 2 бои), два кръга на залагане с разкрита обща карта между тях, действия отказ/плащане/вдигане, фиксирани размери на залога (2 в първия кръг, 4 във втория кръг), максимум две вдигания в един кръг. Класиране на ръка по двойки: тайна карта, която съвпада с общата карта, побеждава всяка висока карта. Изброява всички 120 пермутации на раздаването за точно изчисляване на математическо очакване.

## 3. Реализации на алгоритми

### 3.1 Обикновен вариант на CFR

Пълно обхождане на дърво с вероятностна извадка върху всичките 120 раздавания при всяка итерация. Актуализациите на съжалението се буферират за всяко информационно множество и се прилагат атомарно в края на обхождането на всяко раздаване, с цел да се избегне отклонение от стратегията по средата на итерацията.

### 3.2 CFR+

Три модификации на обикновения вариант на CFR, всяка от които е локализирана. Основната промяна е стъпката за нулиране на отрицателните съжаления:

```python
# cfrplus_trainer.py - regret flooring (ReLU-style clip)
for info_set, deltas in regret_buffer.items():
    node = node_map[info_set]
    for a in range(node.num_actions):
        node.regret_sum[a] = max(node.regret_sum[a] + deltas[a], 0.0)
```

Линейно претегленото усредняване на стратегиите дава на итерация `t` тегло `t` в текущата средна; при редуващите се актуализации двамата играчи се обновяват последователно в рамките на всяка итерация, така че обновяването на втория вече отчита новите съжаления на първия. Обикновеният вариант тук също редува актуализациите, така че двата се различават само по нулирането на отрицателните съжаления и линейното усредняване.

### 3.3 Външно вземане на проби в MCCFR

Взема извадка от едно раздаване на итерация. Във възлите на обхождащия играч се изследват всички действия, докато във възлите на противника се взема проба само от едно действие, избрано според текущата стратегия на противника.

```python
def external_cfr(state, update_player):
    if state.is_terminal():
        return state.get_utility(update_player)

    player = state.current_player()
    strategy = get_strategy(state.info_set(player))

    if player == update_player:
        # explore ALL actions (same as vanilla CFR)
        values = [external_cfr(state.apply(a), update_player)
                  for a in legal_actions]
        node_value = sum(strategy[a] * values[a] for a in legal_actions)
        for a in legal_actions:
            regret[info_set][a] += values[a] - node_value
        return node_value
    else:
        # SAMPLE one opponent action from the current strategy
        sampled_action = sample(strategy)
        return external_cfr(state.apply(sampled_action), update_player)
```

Разходът на итерация е приблизително 42 възела (срещу 20,400 при пълно обхождане).

### 3.4 MCCFR с извадка по резултати

Тегли една-единствена траектория до край. Във възлите на обхождащия играч действията се избират от ε-микс с текущата стратегия (ε = 0.6: равномерно с вероятност ε, в противен случай според текущата стратегия). Актуализациите на съжалението се коригират чрез извадка по важност - отношението между истинската вероятност за достигане и вероятността за извадка - като по този начин се запазва свойството на неизместена оценка. Разходът на итерация е приблизително 5.5 възела.

### 3.5 Оценител на експлоатируемостта

Итеративен най-добър отговор, ограничен до информационно множество: за всеки играч се изчислява оптималната контрастратегия при условие, че отговарящият трябва да изиграе едно и също действие във всички състояния в рамките на дадено информационно множество. Връща `(BR₀(σ₁) + BR₁(σ₀)) / 2` като точна експлоатируемост (конвенцията на OpenSpiel: NashConv / 2).
