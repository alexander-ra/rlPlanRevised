# Step 09 — figures/

The exact experiment PNGs the Step 09 deliverables cite. Per WORKFLOW.md §4.6, every figure
must trace to a real artifact under `implementation/step09/**/{results,figures,plots}`; nothing
here is fabricated. Exploration figures keep their original names; implementation figures are
prefixed `impl_`.

**Status: generated.** matplotlib was not active on the original run, so the scripts wrote only
their `.json`; the PNGs were then drawn from those JSON artifacts (24 Jul 2026) and redrawn for
the final review (24 Sep 2026: print-size fonts, 300 dpi, Bulgarian `_bg` twins). The
`summaryEn.md` / `summaryBg.md` reference them by these filenames.

---

## How to generate them (human step)

From the repo root with the project `.venv` active (needs `matplotlib`):

```bash
cd rlPlanRevised/implementation/step09/exploration
python matrix_games_playground.py      # -> figures/matrix_games_playground.png
python nonstationarity_demo.py         # -> figures/nonstationarity_demo.png
python selfplay_vs_nash.py             # -> figures/selfplay_vs_nash.png
python psro_peek.py                    # -> figures/psro_peek.png
python lola_ipd_playground.py          # -> figures/lola_ipd_playground.png
python plot_results.py                 # redraws all five from the saved JSON (no rerun)

cd ../implementation
python tournament.py --config scale    # (re)writes results/scale_results.json
python plotting.py --config scale       # -> plots/psro_exploitability.png, plots/coop_ctde_comm.png (reads the JSON only)
```

Then copy them here:

```bash
# from rlPlanRevised/
cp implementation/step09/exploration/figures/*.png            deliverables/reports/step09/figures/
cp implementation/step09/implementation/plots/psro_exploitability.png deliverables/reports/step09/figures/impl_psro_exploitability.png
cp implementation/step09/implementation/plots/coop_ctde_comm.png      deliverables/reports/step09/figures/impl_coop_ctde_comm.png
```

The conceptual-diagram PNGs are produced by the `summary/make_*_figure.py` scripts (also a
human step):

```bash
cd rlPlanRevised/deliverables/reports/step09/summary
python make_nonstationarity_figure.py   # -> nonstationarity_dance.png
python make_ctde_figure.py              # -> ctde_architecture.png
python make_psro_loop_figure.py         # -> psro_loop.png
python make_methods_spectrum_figure.py  # -> methods_spectrum.png
```
