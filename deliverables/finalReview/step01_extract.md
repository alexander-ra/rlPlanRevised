## Digest

Reinforcement learning (RL) formalizes sequential decision-making as a Markov decision process (MDP): states, actions, transition probabilities, rewards and a discount factor, with the goal of a policy that maximizes the expected discounted return [1]. The Bellman equation defines a state's value recursively. When the model is known, dynamic programming (policy and value iteration) computes optimal policies exactly [1, 2], at a cost that grows with the number of states. Temporal-difference learning removes the need for a model by bootstrapping from current estimates [3]. Q-learning extends it to off-policy control, with convergence guaranteed in the tabular case [4]. Deep RL replaced tables with neural networks. DQN stabilized Q-learning with experience replay and a periodically synchronized target network, and learned Atari games from raw pixels [5]. Double Q-learning later reduced its overestimation bias [6]. Policy-gradient methods optimize a parameterized policy directly [7]. TRPO restricts each update to a trust region [8], and PPO approximates this with a clipped surrogate objective and first-order updates, usually in an actor–critic form with generalized advantage estimation [9, 10].

These methods assume a single agent in a stationary, fully observable environment. Games violate both assumptions. Under hidden information the decision point is an information set rather than a state [11], and the partially observable generalization of the MDP is computationally hard [12, 13]. When other agents learn, the environment becomes non-stationary, because their policies change as they learn [14]. Independently trained RL policies overfit to the partners they were trained with [15], and on Leduc poker standard RL diverged where fictitious self-play approached a Nash equilibrium [16]. Greedy value-based policies also cannot represent the mixed strategies that equilibrium play requires. These limits motivate the game-theoretic methods that follow, while value networks, policy gradients and replay remain the building blocks of neural equilibrium solvers.

## Gaps
This chapter establishes premises; it does not show a literature gap, and none should be claimed from it. It supports the three gaps in `lit_gaps.md` as follows, without restating any of them more strongly than that file allows:
- **Premise for C1 (adaptation):** single-agent RL assumes a stationary environment, and against learning opponents the target moves [14]. Independently trained policies overfit to their training partners [15]. The value of real-time opponent inference rests on this, but `lit_gaps.md` shows the detect → adapt loop itself is *not* open (GSCU, PACE, StratFormer, AlphaExploitem). Chapter I should use this premise only to motivate the N-player, within-match, safety-coupled extension.
- **Premise for C2 (safety):** a greedy value-based policy cannot represent mixed strategies, and plain RL self-play diverged on Leduc [16]. Exploitation therefore needs an equilibrium anchor, which leads to § 1.3/1.5. No claim about N-player safety follows from this chapter.
- **Premise for C3 (evaluation):** RL agents are conventionally scored by return in a fixed environment (the chapter's own targets are Gymnasium's 475 and 200). In an adversarial game, that score depends on the opponent pool. This is only a motivating contrast; the C3 gap itself rests on `lit_evaluation.md`.
